# Idle Tycoon Game

This repo now includes a terminal-friendly idle tycoon you can play directly in this environment (plus the earlier SwiftUI prototype for iPhone).

## Playing in the terminal

Requirements: Python 3.10+

Run interactively:

```bash
python3 main.py
```

Or run a short scripted demo (useful for quick checks):

```bash
python3 main.py --demo --steps 8
```

Gameplay basics:

- Tap (`t`) to earn coins
- Wait (`w`) to advance time by 5 seconds and collect passive income
- Buy upgrades (`b`) to increase tap strength or passive income
- Quit anytime with (`q`)
